> هدف: یاد بگیری داده را داخل **کادرهای نام‌دار** بگذاری، نوعش را بشناسی، و
> باهاش حساب کنی.

## ۱. متغیر چیست؟

متغیر یک **برچسب** است که به یک مقدار اشاره می‌کند.

```python
age = 25          # یعنی: مقدار 25 را بساز، برچسب age را به آن بچسبان
message = "سلام"
```

⚠️ نکته‌ی کلیدی: `=` در پایتون **مساوی نیست**، **«بریز توی»** است.
`age = 25` را این‌طور بخوان: «مقدار ۲۵ را بریز توی age».
برای مقایسه از `==` استفاده می‌کنیم (بعداً).

### نام‌گذاری متغیر

قانون پایتون (`PEP 8`):

```python
user_name = "علی"      # snake_case برای متغیرها ✅
USER_LIMIT = 10        # UPPER_CASE برای ثابت‌ها ✅
class_name = "Car"     # PascalCase برای کلاس‌ها ✅
```

قواعد ممنوع:
- نمی‌تواند با **عدد** شروع شود → `2name` ❌
- نمی‌تواند **فاصله** داشته باشد → `my name` ❌
- نمی‌تواند **کلیدواژه‌ی پایتون** باشد → `class`, `if`, `for` ❌
- کاراکترهای مجاز: حروف انگلیسی، عدد، `_`

## ۲. انواع داده (Data Types)

پایتون ۴ نوع پایه دارد که هر روز باهاشان سر و کار داریم:

| نوع | مثال | چیست؟ |
|---|---|---|
| `int` | `25` | عدد صحیح |
| `float` | `2.5` | عدد اعشاری |
| `str` | `"سلام"` | متن (رشته) |
| `bool` | `True` / `False` | درست / نادرست |

### ۲.۱ رشته (`str`)

```python
name = "مریم"          # با کوتیشن
city = 'تهران'         # با آپاستروف — هر دو یکی هستند
code = "12345"          # ⚠️ این str است نه int!
```

برای متن چندخطی از سه کوتیشن:

```python
text = """
خط اول
خط دوم
"""
```

### ۲.۲ بولی (`bool`)

```python
is_student = True
has_car = False
```

### ۲.۳ بررسی نوع داده: `type()`

```python
print(type(25))        # <class 'int'>
print(type(2.5))       # <class 'float'>
print(type("hi"))      # <class 'str'>
print(type(True))      # <class 'bool'>
```

### ۲.۴ تبدیل نوع (Type Casting)

```python
s = "123"
print(type(s))         # str
n = int(s)
print(type(n))         # int

print(float("3.14"))   # 3.14
print(str(100))        # "100"
print(bool(0))         # False
print(bool(""))        # False
print(bool("hello"))   # True
```

## ۳. عملگرها

### ۳.۱ حسابی

| عملگر | کار | مثال | نتیجه |
|---|---|---|---|
| `+` | جمع | `5 + 3` | `8` |
| `-` | تفریق | `5 - 3` | `2` |
| `*` | ضرب | `5 * 3` | `15` |
| `/` | تقسیم | `5 / 2` | `2.5` ← همیشه `float`! |
| `//` | تقسیم صحیح | `5 // 2` | `2` |
| `%` | باقیمانده | `5 % 2` | `1` |
| `**` | توان | `2 ** 10` | `1024` |

⚠️ تقسیم `/` همیشه اعشاری برمی‌گرداند، حتی اگر بخش‌پذیر باشد:
`10 / 5` → `2.0` نه `2`.

### ۳.۲ مقایسه‌ای (نتیجه‌شان `bool` است)

```python
5 == 5      # True   (برابری)
5 != 3      # True   (نابرابری)
5 > 3       # True
5 >= 5      # True
5 < 3       # False
5 <= 3      # False
```

```python
print(10 / 2 == 5)    # True  →  5.0 == 5  → True
print(10 // 2 == 5)   # True
```

### ۳.۳ منطقی

| عملگر | معنی | مثال |
|---|---|---|
| `and` | هر دو باید درست باشند | `age >= 18 and has_id` |
| `or` | یکی کافی است | `is_vip or age >= 18` |
| `not` | معکوس | `not is_student` |

⚠️ `and` / `or` / `not` کلمات کلیدی‌اند و بینشان `&` و `|` نگذار.

### ۳.۴ انتساب زنجیره‌ای و افزایش/کاهش

```python
a = b = c = 0        # هر سه صفر
x = 10
x += 5               # x = x + 5  → 15
x -= 3               # 12
x *= 2               # 24
x /= 4               # 6.0
x **= 2              # 36.0
x //= 5              # 7.0
x %= 3               # 1.0
```

`x += 1` را با `x = x + 1` اشتباه نگیر — اولی کوتاه‌تر و رایج‌تر است.

## ۴. چند نکته‌ی زبان پایتون (خلاصه، برای آشنایی)

### ۴.۱ Indentation (تورفتگی) — مهم‌ترین قاعده‌ی پایتون

بلوک‌ها (بدنه‌ی `if`، حلقه، تابع) با **تورفتگی** مشخص می‌شوند، نه با `{}`.
قرارداد: **۴ فاصله**.

```python
age = 20

if age >= 18:
    print("بزرگسال")
else:
    print("نوجوان")
```

در VS Code تب را بزنی، خودش ۴ فاصله می‌گذارد.

### ۴.۲ کامنت

با `#` شروع می‌شود تا آخر خط.

### ۴.۳ چند مقدار در یک خط

```python
a, b = 10, 20          # a=10, b=20
x, y = y, x             # جابه‌جایی
```
