## ۱. اجرای پایتون

سه راه داری. هرکدام را که راحت‌تری است استفاده کن:

### الف) ویرایشگر VS Code (پیشنهاد من)

۱. VS Code را نصب کن و افزونه‌ی **Python** (Microsoft) را اضافه کن.
۲. یک پوشه‌ی خالی بساز و فایل `hello.py` در آن قرار بده.
۳. کد را بنویس و برای اجرا `Ctrl + F5` را بزن (یا دکمه ▶️ بالا-راست).

### ب) خط فرمان (Command Prompt / PowerShell)

```powershell
cd path\to\your\folder
python hello.py
```

### پ) حالت تعاملی (برای آزمایش سریع)

```powershell
python
```

این حالت یک خط فرمان داخل پایتون باز می‌کند. با `exit()` یا `Ctrl+Z` و `Enter` از آن خارج شو.

## ۲. اولین برنامه

```python
# hello.py
print("سلام دنیا!")
print("من دارم پایتون یاد می‌گیرم.")
```

اجرا: `python hello.py`

### چند نکته‌ی مهم درباره‌ی `print`

```python
print("a", "b", "c")            # a b c   → با فاصله جدا می‌شود
print("a", "b", sep=" - ")      # a - b   → جداکننده‌ی دلخواه
print("a", end="")               # بدون خط جدید
print("b")                       # b      → نتیجه: ab
print(f"سال تولد من {1370} است")  # f-string → 1370 داخل متن می‌آید
```

**f-string** را جدی بگیر؛ از این به بعد در ۹۰٪ کدها از آن استفاده می‌کنیم.
هر چیزی داخل `{}` می‌تواند یک عبارت پایتونی باشد:

```python
name = "مریم"
age = 25
print(f"{name} {age} سال دارد و {age * 12} ماه عمر کرده است.")
```

## ۳. گرفتن ورودی از کاربر

```python
name = input("نامت چیه؟ ")
print(f"سلام {name}!")
```

⚠️ **نکته‌ی بسیار مهم:** خروجی `input` همیشه **رشته** است، حتی اگر کاربر عدد تایپ کند.

```python
x = input("عدد بده: ")   # x == "25"  (رشته!)
print(x + 1)               # ❌ TypeError: can only concatenate str
```

برای تبدیل به عدد:

```python
x = int(input("عدد بده: "))     # int("25") → 25
y = float(input("عدد اعشاری: ")) # float("2.5") → 2.5
```

اگر کاربر چیزی غیرعددی وارد کند، برنامه کرش می‌کند (در درس ۵ یاد می‌گیریم
چطور جلویش را بگیریم).

## ۴. کامنت چیست؟

```python
# این یک کامنت تک‌خطی است — پایتون آن را نمی‌خواند

"""
این یک کامنت چندخطی است.
برای توضیح بلند یا غیرفعال‌کردن چند خط کد استفاده می‌شود.
"""
```

کامنت را برای **«چرا»** بنویس، نه برای **«چه»**. این بد است:

```python
# i را یکی اضافه کن
i += 1
```

این خوب است:

```python
# تا وقتی کاربر ورودی نامعتبر دارد، دوباره می‌پرسیم
while True:
    raw = input("عدد: ")
    ...
```

## ۵. خطاها را نترس!

اگر پایتون خطا داد، این خبر خوبی است — یعنی برنامه اجرا شد و به مشکل خورد.
پیام خطا را کامل بخوان، مخصوصاً **آخرین خط** را:

```
Traceback (most recent call last):
  File "hello.py", line 3, in <module>
    print(name)
NameError: name 'name' is not defined
                     ^^^^^^^^^^^^^^^^^
```

سه چیز از این پیام درمی‌آید:
- **نوع خطا**: `NameError` (خطای نام)، `TypeError` (نوع نادرست)، `IndentationError`، `SyntaxError`، ...
- **شماره‌ی خط**: `line 3` → برو به خط ۳
- **خودِ مشکل**: معمولاً آخرین خط پیام دقیقاً می‌گوید چه شد

`NameError` یعنی متغیری را استفاده کردی که هنوز نساخته‌ای یا املایش غلط است.
