# پروژه ۱ — مدیریت کارهای روزانه (پایه‌ی مسیر اتوماسیون)

> **هدف:** یک برنامه‌ی خط فرمان که کارها را در یک فایل JSON نگه می‌دارد.
> این پروژه تقریباً همه‌ی چیزهایی را که تا درس ۵ یاد گرفتی را یک‌جا به کار می‌گیرد.

---

## صورت مسئله

برنامه‌ای بنویس به اسم `tasks.py` که این کارها را بکند:

```
> python tasks.py add خرید نان
  ✅ کار اضافه شد.

> python tasks.py list
  [1] خرید نان          (انجام نشده)
  [2] مطالعه پایتون     ✔ انجام شده

> python tasks.py done 1
  ✔ کار 1 انجام شد.

> python tasks.py remove 2
  🗑 کار 2 حذف شد.
```

---

## داده‌ها

کارها در فایل `tasks.json` ذخیره می‌شوند:

```json
[
  {"id": 1, "title": "خرید نان", "done": false},
  {"id": 2, "title": "مطالعه پایتون", "done": true}
]
```

---

## الزامات فنی

۱. **جدا کردن منطق از رابط کاربری.** توابع پایه (خواندن، نوشتن، افزودن، حذف)
   در فایل `task_manager.py` باشند، و `tasks.py` فقط ورودی/خروجی را مدیریت کند.

۲. **تابع‌ها به این شکل باشند:**

   | تابع | کار |
   |---|---|
   | `load_tasks(path)` | لیست کارها را از JSON بخواند (اگر فایل نبود → `[]`) |
   | `save_tasks(path, tasks)` | کارها را در JSON ذخیره کند |
   | `add_task(tasks, title)` | کار جدید با id یکتا اضافه کند |
   | `complete_task(tasks, task_id)` | وضعیت را به انجام‌شده تغییر دهد |
   | `remove_task(tasks, task_id)` | کار را حذف کند |
   | `find_task(tasks, task_id)` | کار با id را برگرداند یا None |

۳. **مدیریت خطا:**
   - اگر `tasks.json` خراب بود (JSON نامعتبر) → پیام خطای قابل‌فهم بده
   - اگر `id` کاربر وجود نداشت → پیام "کار با شناسه X پیدا نشد"

۴. **استفاده از `argparse`** برای پارامترها (درس ۷).

۵. **مقیاس‌پذیری:** تابع‌ها `path` بگیرند تا بتوانی تست کنی (فایل واقعی را
   دست نزنی).
